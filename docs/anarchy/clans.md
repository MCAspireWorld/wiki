# 🛡️ Кланы

Меню и команды кланов: **`/clan`**.

## Создание клана

<div class="aw-steps" markdown>

### Придумай тег

Тег клана — от **3 до 6** символов. Он показывается рядом с ником в скорборде и табе.

### Создай клан

Создание стоит **5 000 монет**.

### Приглашай игроков

Приглашай друзей в клан и назначай им ранги.

</div>

## Возможности

| Что | Описание |
|---|---|
| Тег клана | `[ТЕГ]` рядом с ником |
| Клановый чат | отдельный чат только для участников клана |
| Ранги | роли внутри клана с разными правами |
| Топ кланов | рейтинг кланов сервера |

!!! tip "Клан и рейды"
    Добавляй соклановцев в свой [приват](regions.md) командой `/ps add <ник> <номер>`, чтобы они могли строить на вашей базе.
