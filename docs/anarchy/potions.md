# 🧪 Зелья

## Улучшенные зелья

На **наковальне** можно усилить зелья сверх ванильного максимума:

| Зелье | Как получить | Результат |
|---|---|---|
| **Сила III** | два зелья Силы II | Сила III на 3 минуты |
| **Скорость III** | два зелья Скорости II | Скорость III на 3 минуты |

## Смешанные зелья

Два **разных** зелья на наковальне → **смешанное зелье** со всеми эффектами сразу, например Сила + Скорость + Огнестойкость.

- До **4 эффектов** в одном зелье.
- Только **полезные** эффекты.
- Зелья должны быть одного вида: обычное с обычным, взрывное со взрывным, туманное с туманным.

## Стаки зелий

Зелья складываются в стаки **до 64** — в инвентаре, при подборе с земли и из варочной стойки.

!!! warning "В бою"
    В [режиме PvP](pvp.md) у зелий есть задержка: 5 секунд между использованиями.
