# 🧭 Команды

## Меню и информация

| Команда | Что делает |
|---|---|
| `/menu` | Главное меню сервера |
| `/profile [ник]` | Профиль игрока: статистика, рейтинг, отзывы |
| `/tops` | Топы по монетам, убийствам, смертям и часам |
| `/events` | Меню ивентов |
| `/rules`, `/help` | Правила и помощь |
| `/donate` | Привилегии |
| `/premium` | Статусы [Premium и Platinum](premium.md) за кроны |
| `/settings` | Настройки |
| `/ping`, `/playtime`, `/list` | Пинг, наигранное время, онлайн |

## Телепорт и дома

| Команда | Что делает |
|---|---|
| `/rtp` | Случайный телепорт в дикий мир |
| `/spawn` | На спавн |
| `/home`, `/sethome`, `/delhome` | Точки дома |
| `/tpa <ник>` | Запрос на телепорт к игроку (кнопки Принять / Отклонить в чате) |
| `/tpahere <ник>` | Позвать игрока к себе |
| `/tpaccept`, `/tpdeny`, `/tpacancel` | Принять, отклонить, отменить запрос |
| `/back` | Вернуться на прошлое место |
| `/warp` | Варпы |

## Экономика

| Команда | Что делает |
|---|---|
| `/balance`, `/baltop` | Баланс и топ богачей |
| `/pay <ник> <сумма>` | Перевод монет (нужно подтвердить повтором команды) |
| `/salary` | Меню зарплаты (раз в 24 часа, серия дней) |
| `/sell` | Продать ресурсы скупщику |
| `/shop`, `/market` | Магазин и рынок |
| `/ah` | [Аукцион](auction.md) |
| `/casino` | [Игровой зал](casino.md) |
| `/exp` | [Обмен опыта на колбы](exp.md) |

## Регионы и рейды

| Команда | Что делает |
|---|---|
| `/ps` | Управление регионами (добавить игрока, границы, переименовать) |
| `/ps add <ник> <номер>` / `/ps rem <ник> <номер>` | Добавить / убрать участника |
| `/ps show <номер>` | Показать границы региона |
| `/raid-link` | Привязать Telegram — уведомления о рейдах на твой регион |

## Ивенты и развлечения

| Команда | Что делает |
|---|---|
| `/pesok` | [Песчаные Раскопки](pesok.md) |
| `/minievent` (`/mev`) | Где сейчас мини-ивент и когда следующий |
| `/event gps` | Координаты активных ивентов |
| `/event vote` | Голосование за следующий ивент |
| `/aanvil` | Меню [наковальни](anvil.md) |
| `/crafts` (`/крафты`) | Рецепты кастомных крафтов: рюкзаки, броня Одина и Фенрира, автобаферы и др. |
| `/книги`, `/магазинкниг` | Каталог и магазин [кастомных книг](anvil.md#кастомные-книги) |
| `/шахта`, `/кирки` | Автошахта на спавне: скупщик руды и кирки |
| `/fisherman` | Рыбак: удочки, продажа улова |
| `/обучение` | Задания для новичков с наградами |
| `/battlepass`, `/quests` | [Боевой пропуск](battlepass.md) и задания |
| `/case` | [Кейсы](kits.md) |
| `/clan` | [Кланы](clans.md) |

## Общение

| Команда | Что делает |
|---|---|
| `/msg <ник> <текст>`, `/r` | Личные сообщения |
| `/ignore <ник>` | Игнорировать игрока |
| `/report <ник>` | [Жалоба](reports.md) |
| `/spec` | Попросить модератора понаблюдать за тобой |

## Донатные команды

Список зависит от привилегии: `/ec`, `/fix`, `/feed`, `/heal`, `/fly` и другие — см. [Привилегии](donate.md).
