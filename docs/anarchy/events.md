# 🗺️ Большие ивенты

Крупные ивенты со структурами: **Воздушный корабль**, **Посылка**, **Торговец**, **Якорь**, **Кладбище**, **Алтарь Смерти** и другие. Внутри — сундуки с лутом разной редкости, иногда охрана из мобов.

<div class="aw-steps" markdown>

### Появление

Когда появляется ивент, в чат приходит сообщение с названием, координатами и редкостью.

### Открытие

Сундуки открываются не сразу — таймер виден в боссбаре и над ивентом. Успей добраться и занять место.

### Лут

Когда сундуки открыты, забирай лут, пока ивент не закрылся.

</div>

## Команды

| Команда | Что делает |
|---|---|
| `/event gps` | Координаты активных ивентов |
| `/event delay` | Когда следующий ивент |
| `/event vote` | Голосование за следующий ивент |
| `/events` | Меню всех ивентов сервера |
