# 🧱 Защитные блоки

| Блок | Как ломается |
|---|---|
| **Обсидиан** | Обычный взрыв не берёт — только [заряды по обсидиану](tnt.md) |
| **Плачущий обсидиан** | От **любого** взрыва рядом превращается в обычный обсидиан |
| **Укреплённый сланец** | Три удара зарядом по обсидиану, руками и обычным взрывом не ломается |

## Укреплённый сланец

Самый прочный защитный блок сервера. Выглядит как укреплённый глубинный сланец.

<div class="aw-steps" markdown>

### Сланец

Целый блок. Первый удар зарядом по обсидиану превращает его в плачущий обсидиан.

### Плачущий обсидиан

Второй удар превращает его в обычный обсидиан.

### Обсидиан

Третий удар разрушает блок полностью.

</div>

- Проверить, сколько ударов осталось: **присесть и нажать ПКМ пустой рукой** по блоку.
- Руками, обычными взрывами, поршнями его не сломать и не сдвинуть.
- Купить: `/shop`, 25 крон. Также встречается у Торговца Смерти и в луте ивентов.

!!! tip "Как строить защиту"
    Плачущий обсидиан — не самая надёжная стена: первый же взрыв рядом превращает его в обычный обсидиан. Основу защиты строй из **укреплённого сланца** — каждый заряд снимает с него только одну стадию, так что на пробитие толстой стены уйдёт много динамита.
