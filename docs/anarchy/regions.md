# 🏡 Приваты

Приват защищает постройку: внутри строить и ломать могут только владелец и участники.

## Как поставить

<div class="aw-steps" markdown>

### Возьми маркер региона

Приват создаётся **маркером региона** — особым блоком.

### Поставь его

Вокруг маркера появится регион. Сколько приватов можно поставить, зависит от [привилегии](donate.md): от **1** до **10**.

### Добавь друзей

`/ps add <ник> <номер>` — до 10 участников в одном регионе.

</div>

## Команды

| Команда | Что делает |
|---|---|
| `/ps` | Меню приватов |
| `/ps add <ник> <номер>` | Добавить участника |
| `/ps rem <ник> <номер>` | Убрать участника |
| `/ps show <номер>` | Показать границы |
| `/ps rename <номер> <имя>` | Переименовать |
| `/ps info <номер>` | Информация о регионе |
| `/raid-link` | Привязать Telegram — придёт уведомление, если твой приват рейдят |

## Прочность и рейды

У маркера региона есть **прочность**. Кастомный [динамит](tnt.md), взорвавшийся у маркера, снимает её. Когда прочность кончилась, регион разрушается и базу можно грабить.

- **Ремкомплекты** восстанавливают прочность — кликни ремкомплектом по маркеру. Продаются в магазине.
- После урона ремонт доступен не сразу.
- Во время рейда на регион включается **рейд-блок** — ограничения для игроков внутри.

!!! info "Эффекты региона"
    В меню привата можно открыть слоты **эффектов** — постоянных баффов для игроков на территории региона.

Чем защитить саму базу — на странице [🧱 Защитные блоки](blocks.md).
