# Регионы и рейды

## Регион

Регион защищает постройку: внутри строить и ломать могут только владелец и участники. Регион создаётся **маркером региона** — особым блоком: поставь его, и вокруг появится приват.

| Команда | Что делает |
|---|---|
| `/ps` | Меню регионов |
| `/ps add <ник> <номер>` | Добавить участника (до 10) |
| `/ps rem <ник> <номер>` | Убрать участника |
| `/ps show <номер>` | Показать границы |
| `/ps rename <номер> <имя>` | Переименовать |
| `/raid-link` | Привязать Telegram — придёт уведомление, если твой регион рейдят |

Сколько регионов можно поставить, зависит от [привилегии](donate.md): от 1 до 10.

### Прочность

У маркера региона есть **прочность**. Кастомный динамит, взорвавшийся рядом с маркером, снимает её. Когда прочность кончилась, регион разрушается и базу можно грабить. Ремкомплекты региона продаются в магазине.

Во время рейда на регион включается **рейд-блок** — ограничения для игроков внутри.

## Защитные блоки

| Блок | Как ломается |
|---|---|
| **Обсидиан** | Обычный взрыв не берёт — только динамиты «по обсидиану» |
| **Плачущий обсидиан** | От **любого** взрыва рядом превращается в обычный обсидиан |
| **Укреплённый сланец** | Три стадии: сланец → плачущий обсидиан → обсидиан → разрушен. Каждую стадию снимает только динамит по обсидиану. Руками и обычным взрывом не ломается. Проверить стадию: присесть и нажать ПКМ пустой рукой |

## Динамиты { #dinamity }

Взрыв обычных блоков — сфера заданного радиуса; обсидиан, бедрок и другие очень прочные блоки обычный взрыв не берёт. Защищённые зоны (спавн, чужие приваты вне рейда, ивенты) взрыв не трогает.

| Динамит | Что делает | Цена в магазине |
|---|---|---|
| **Кромочный заряд** | Ломает только соседний обсидиан: по бокам, сверху и снизу | 19 крон |
| **Пробойный заряд** | Ломает только соседний обсидиан, **работает под водой** | 29 крон |
| **Осадный заряд** | Ломает весь обсидиан в радиусе 2 блоков | 49 крон |
| **Громовой заряд** | Очень мощный взрыв (радиус 6), обсидиан не берёт | 29 крон |
| **Глубинный заряд** | Мощный взрыв даже **под водой**, обсидиан не берёт | 29 крон |
| **Ловец спавнеров** | Выбивает ближайший спавнер с шансом 50% — он выпадает предметом | 39 крон |
| **Мастер-ловец спавнеров** | То же с шансом 90% | 49 крон |
| **Небесный заряд** | Взлетает на 15 блоков и взрывается как обычный динамит | 29 крон |
| **Небесный пробойник** | Взлетает на 15 блоков и ломает весь обсидиан в радиусе 1 | 39 крон |
| **Укреплённый сланец** | Защитный блок, см. выше | 25 крон |

!!! tip "Под водой"
    Обычные динамиты под водой блоки не ломают и способности не применяют — для воды нужны **Глубинный** и **Пробойный** заряды.

!!! info "Заряд ветра"
    Заряд ветра не считается взрывом: он не включает рейд-блок и не превращает плачущий обсидиан.
