# AspireWorld Wiki

Вики сервера **AspireWorld** (`mc.aspireworld.ru`, Minecraft 1.21.4): https://mcaspireworld.github.io/wiki/

## Как редактировать

Статьи лежат в `docs/` в формате Markdown. Любое изменение в ветке `main` автоматически публикуется на сайт (GitHub Actions → GitHub Pages) примерно за минуту.

Локальный просмотр:

```bash
pip install mkdocs-material
mkdocs serve
```
